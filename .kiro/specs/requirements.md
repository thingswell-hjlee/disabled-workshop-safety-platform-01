# Platform 1.0 상세 요구사항 (Requirements)

> **참조:** #[[file:.kiro/specs/inception.md]]
> **범위:** Platform 1.0 (DeepStream 기반 실시간 감지·판단·알람)
> **설계 기준:** Platform 3.0 확장 가능 아키텍처 (TAO + DeepStream SaaS)

---

## 1. 개요

### 1.1 문서 목적

NVIDIA DeepStream SDK + TAO Toolkit + TensorRT를 핵심 기술로 적용한 Platform 1.0의 기능/비기능 요구사항을 정의한다.

### 1.2 요구사항 ID 체계

| 접두사 | 분류 |
|--------|------|
| `FR-DS-xxx` | DeepStream 파이프라인 요구사항 |
| `FR-TAO-xxx` | TAO Toolkit 학습·최적화 요구사항 |
| `FR-DEV-xxx` | 장비 연동 요구사항 |
| `FR-EVT-xxx` | 이벤트 처리·알람 요구사항 |
| `FR-DSH-xxx` | 대시보드 요구사항 |
| `FR-CLD-xxx` | 클라우드 연동 요구사항 |
| `NFR-xxx` | 비기능 요구사항 |

### 1.3 우선순위

| 등급 | 설명 |
|------|------|
| **P0** | Platform 1.0 검수 합격 필수 |
| **P1** | 출시 포함되어야 하나 제한적 동작 허용 |
| **P2** | 2.0 이월 가능 |
