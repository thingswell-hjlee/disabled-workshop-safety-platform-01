# Tests

테스트 코드 및 테스트 설정입니다.

## 구성

| 폴더 | 설명 | 도구 |
|------|------|------|
| `unit/` | 개별 함수·모듈 단위 테스트 | pytest |
| `integration/` | 서비스 간 연동 테스트 | pytest + Docker |
| `e2e/` | End-to-End 시나리오 테스트 | pytest + 시나리오 스크립트 |

## Platform 1.0 검수 테스트

1. **단위 테스트**: 각 서비스별 핵심 로직
2. **통합 테스트**: 센서→Edge AI→알람→대시보드 파이프라인
3. **시나리오 테스트**: 낙상, 화재, 위험구역 침입 등
4. **장애 테스트**: 네트워크 장애, 장비 장애 대응
5. **장기 운영 테스트**: 72시간 연속 운영 안정성
