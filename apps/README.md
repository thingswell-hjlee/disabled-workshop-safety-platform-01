# Apps

## 구성

| App | 설명 | 기술 |
|-----|------|------|
| `dashboard-ui` | 관리자 대시보드 웹 UI | React, Next.js |
| `dashboard-backend` | 대시보드 REST/WebSocket API | FastAPI, Python |

- 실시간 카메라 영상 표시 (8채널)
- 환경센서 데이터 차트
- 작업자 상태 목록
- 이벤트 로그 조회
- 시스템 상태 모니터링
- 관리자 인증 (ID/PW)
