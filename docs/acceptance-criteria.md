| F-04 | 환경센서 연동 | 2센서 온도/습도/CO/VOC 정상 수집 | 데이터 수신 확인 | FR-DEV-007~009 |

## 3. 비기능 검수 (8항목, 전 합격 필수)

| # | 검수 항목 | 합격 기준 | 검증 방법 | 관련 요구사항 |
|---|-----------|-----------|-----------|--------------|
| NF-01 | 네트워크 독립 동작 | 인터넷 차단 시 감지→판단→알람 100% 동작 | 케이블 분리 테스트 | NFR-007 |
| NF-02 | 네트워크 복구 동기화 | 복구 후 5분 이내 이벤트 클라우드 동기화 | 장애→복구 시나리오 | NFR-008 |

| # | 검수 항목 | 합격 기준 | 검증 방법 | 비고 |

## 7. 검수 절차

1. **사전 준비** (1일): 전 장비 활성화, 네트워크 확인, 설정 검증
2. **기능 검수** (2일): F-01~F-12 순차 수행
3. **비기능 검수** (1일): NF-01~NF-08 수행
4. **AI 성능 검수** (1일): AI-01~AI-05 시나리오 수행
5. **보안 검수** (0.5일): S-01~S-04 수행
6. **72시간 장기 운영** (3일): 연속 운영 + 12시간 간격 이벤트 주입
7. **운영 검수** (0.5일): O-01~O-04 수행
8. **최종 판정** (1일): 결과 종합 → 검수 보고서 작성

### 판정 기준

| 결과 | 조건 |
|------|------|
| **합격** | 기능+비기능+AI+보안 전 합격 + 운영 75%+ |
| **조건부 합격** | P1 항목 1~2개 미충족 (30일 내 보완 조건) |
| **불합격** | P0 항목 1개 이상 미충족 |
